# Solution Compare

Use when a reference/official solution is supplied after the student's attempt.

## Steps

1. Verify the reference solution independently; do not assume it is superior merely because it is official.
2. Compare the two approaches on:
   - core insight;
   - proof length/technical load;
   - rigor risk;
   - natural discoverability in contest conditions;
   - prerequisite sophistication;
   - generalizability;
   - clarity of exposition.
3. Identify ideas unique to the student's solution that are worth preserving.
4. Identify ideas from the reference solution that should be added to the learning note.
5. Update method/concept tags only when the new solution reveals genuinely new classifications.

Do not overwrite the student's original review. Append the comparison as a separate section in the note.
