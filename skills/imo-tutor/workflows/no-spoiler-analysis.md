# No-Spoiler Analysis

This workflow enforces `SOLUTION_LOCKED` before the student submits a solution.

## Allowed at H0

- Restate/clarify the problem.
- Give domain, global difficulty, broad knowledge prerequisites, and non-decisive observations about problem form.
- Ask the student to attempt the problem.

## Locked at H0

Do not disclose any item that would materially collapse the search space, including:

- final answer or final theorem-specific conclusion;
- decisive auxiliary construction;
- decisive substitution or normalization;
- decisive lemma;
- a sequence of intermediate goals that effectively forms the solution outline;
- method tags when the method itself is the main discovery.

## Unlock condition

Locked solution analysis remains hidden until either:

- the student explicitly requests hints, in which case disclose only the current hint level; or
- the student submits an attempt, in which case use the full analysis to review the attempt.
